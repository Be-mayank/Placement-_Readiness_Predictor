# DECISIONS.md

## 1. Duplicate removal
The supplied dataset contains repeated records. Duplicates are removed before splitting the data so that the same record cannot appear in both train and test sets.

## 2. Identifier removal
`name` and `email` are excluded because they are identifiers, not generalizable predictive features.

## 3. Free-text removal
`opinion` is excluded from the core model because it requires NLP/text vectorization. The task can be completed using the structured attributes.

## 4. Remove `other_course`
`other_course` is treated as a companion field for the `Other` course category and is excluded from the core feature set.

## 5. Feature engineering
The semicolon-separated `languages` and `certifications` columns are converted into counts and selected binary indicators so conventional classifiers can use the information.

## 6. Pipeline preprocessing
Imputation, scaling and one-hot encoding are performed inside a scikit-learn pipeline to keep training and test transformations consistent.

## 7. Model change
The model comparison uses **Logistic Regression + Decision Tree** rather than Random Forest. The task requires at least two simple classification models and does not require Random Forest specifically. Logistic Regression provides a linear baseline, while Decision Tree provides an interpretable nonlinear model.

## 8. Decision Tree constraints
`max_depth=5`, `min_samples_split=10`, and `min_samples_leaf=5` are used to control tree complexity and reduce overfitting. `class_weight="balanced"` helps account for the class distribution.

## 9. Metric choice
Precision, Recall and F1-score are emphasized because accuracy alone does not show the quality of positive placement predictions or the ability to identify placed students.

## 10. Stratified split
An 80/20 split with `stratify=y` is used so the two target classes remain approximately represented in both sets.

## 11. No hard-coded results
All metrics are generated by executing the notebook on the supplied CSV. Exact scores are intentionally not hard-coded.

## 12. Interpretability
Decision Tree feature importance is displayed so the model's most influential encoded features can be inspected.

## 13. Limitation
The model is an estimate learned from the supplied dataset. It is not a guarantee of placement and may not generalize to different institutions, hiring processes or future placement cycles.
